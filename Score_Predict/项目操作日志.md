## 📖 项目概述

### 项目简介
这是一个基于 Web 的问卷调研系统，用于评估高考复读生的提分潜力。通过 30 道题目（分为4个维度）评估学生是否适合复读以及预期提分空间。

### 核心功能
- ✅ 30 道题问卷调研（7点量表）
- ✅ 智能评分系统（复杂计分规则）
- ✅ 结果分析和建议
- ✅ 云端数据存储（Supabase）
- ✅ 数据统计和可视化管理
- ✅ AI 聊天助手（Dify）

### 技术栈
- **前端**: 纯 HTML + CSS + JavaScript（无需构建工具）
- **数据库**: Supabase (PostgreSQL)
- **AI 助手**: Dify
- **部署**: 本地 HTTP 服务器 / 云端托管

#### 问题 2: Supabase 数据提交失败（Failed to fetch）

**现象**:
```
⚠️ 数据保存到 Supabase 失败，但已保存到本地: TypeError: Failed to fetch
```

**原因**: 
- 直接用浏览器打开 HTML 文件（`file://` 协议）
- Supabase SDK 需要通过 HTTP/HTTPS 协议才能工作
- 浏览器的同源策略限制

**解决方案**:
必须通过 HTTP 服务器访问，提供了 5 种启动方法：

1. **Python 方法**（推荐）
```bash
python3 -m http.server 8000
# 访问: http://localhost:8000/index.html
```

2. **Node.js 方法**
```bash
npx http-server -p 8000
```

3. **PHP 方法**
```bash
php -S localhost:8000
```

4. **VS Code Live Server 扩展**
- 右键 HTML 文件 → Open with Live Server

5. **在线部署**
- GitHub Pages
- Vercel
- Netlify

**产出文件**:
- ✅ `启动本地服务器.md` - 详细启动方法
- ✅ `start.sh` - Mac/Linux 启动脚本
- ✅ `start.bat` - Windows 启动脚本
- ✅ `如何启动.txt` - 简明启动说明

#### 问题 3: Supabase 权限配置

**现象**: 
数据无法插入数据库，即使服务器正常运行

**原因**: 
Supabase 的 RLS (Row Level Security) 默认阻止所有操作

**解决方案**:
执行权限配置 SQL：

```sql
-- 启用 RLS
ALTER TABLE survey_results ENABLE ROW LEVEL SECURITY;

-- 允许匿名插入数据
CREATE POLICY "允许公开插入" ON survey_results
FOR INSERT TO anon WITH CHECK (true);

-- 允许匿名读取数据（用于管理面板）
CREATE POLICY "允许公开读取" ON survey_results
FOR SELECT TO anon USING (true);
```

**产出文件**:
- ✅ `set-permissions.sql` - 权限配置脚本

### 阶段三：AI 聊天助手集成

#### 目标
在结果页面集成 Dify AI 聊天助手，为用户提供个性化咨询服务。

#### 问题与解决

##### 问题: CSP (Content Security Policy) 限制

**现象**:
```
Refused to execute inline script because it violates the following 
Content Security Policy directive
```

**原因**: 
Dify 的嵌入代码包含内联脚本，违反了浏览器的 CSP 安全策略

**解决方案**:
将配置代码拆分为外部文件：

1. **创建配置文件** (dify-config.js)
```javascript
window.difyChatbotConfig = {
    token: 'EeZuoXEJYHEI8rjv',
    inputs: {},
    systemVariables: {},
    userVariables: {}
}
```

2. **创建样式文件** (dify-style.css)
```css
#dify-chatbot-bubble-button {
    background-color: #1C64F2 !important;
    /* 自定义样式 */
}
```

3. **在 result.html 中引入**
```html
<head>
    <link rel="stylesheet" href="dify-style.css">
</head>
<body>
    <script src="dify-config.js"></script>
    <script src="https://udify.app/embed.min.js" 
            id="EeZuoXEJYHEI8rjv" defer>
    </script>
</body>
```

**技术集成**: ✅ 完成  
**功能测试**: ⚠️ 需要配置 Dify 后台

**注意**: 用户遇到 403 错误（需要付费模型），需要在 Dify 后台切换为免费模型。

**产出文件**:
- ✅ `dify-config.js` - Dify 配置
- ✅ `dify-style.css` - 聊天助手样式
