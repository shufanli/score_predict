========================================
  如何启动问卷系统 - 3种方法
========================================

问题原因：
浏览器直接打开 HTML 文件无法使用 Supabase
必须通过 HTTP 服务器访问！

========================================

【方法1】最简单 - 使用启动脚本 ⭐推荐
----------------------------------------

Mac / Linux 用户：
1. 双击运行 start.sh
2. 如果无法运行，在终端执行：
   ./start.sh

Windows 用户：
1. 双击运行 start.bat

然后浏览器访问：
http://localhost:8000/index.html


【方法2】手动命令 - Mac/Linux
----------------------------------------

1. 打开终端（Terminal）
2. 进入项目目录：
   cd /Users/bzl/lishufan/代码文件/我的代码/score_predict/Score_Predict
3. 运行命令：
   python3 -m http.server 8000
4. 浏览器访问：
   http://localhost:8000/index.html


【方法3】VS Code 扩展
----------------------------------------

1. 安装 Live Server 扩展
2. 右键点击 index.html
3. 选择 "Open with Live Server"
4. 自动打开浏览器


========================================
  验证是否成功
========================================

✅ 浏览器地址栏显示：
   http://localhost:8000/index.html

✅ 按 F12 打开控制台，看到：
   Supabase 客户端初始化成功
   ✅ 数据已成功保存到 Supabase

❌ 如果地址栏显示：
   file:///Users/...
   说明方法不对，需要用上面的方法！


========================================
  常见问题
========================================

Q: 显示 "Address already in use"
A: 端口被占用，使用其他端口：
   python3 -m http.server 8001

Q: 找不到 python3 命令
A: 使用 python 或从 python.org 下载安装

Q: 仍然显示 Failed to fetch
A: 1. 确认是 http:// 不是 file://
   2. 确认已执行 set-permissions.sql
   3. 检查 Supabase 项目状态
