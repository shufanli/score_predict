
- [ ] 3.4 找到并复制 "anon public" key

## ⚙️ 第四步：配置项目文件

- [ ] 4.1 打开项目中的 `supabase-config.js` 文件
- [ ] 4.2 找到以下代码：
      ```javascript
      const SUPABASE_CONFIG = {
          url: 'YOUR_SUPABASE_URL',
          anonKey: 'YOUR_SUPABASE_ANON_KEY'
      };
      ```
- [ ] 4.3 将 `YOUR_SUPABASE_URL` 替换为你的 Project URL
- [ ] 4.4 将 `YOUR_SUPABASE_ANON_KEY` 替换为你的 anon public key
- [ ] 4.5 保存文件
- [ ] 4.6 确认没有多余的空格或引号

**状态**: ⬜ 未完成 / ✅ 已完成

**正确示例**:
```javascript
const SUPABASE_CONFIG = {
    url: 'https://abcdefghijk.supabase.co',
    anonKey: 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJzdXBhYmF...'
};
```

## 🔓 第五步：设置数据库权限（RLS）

- [ ] 5.1 在 Supabase SQL Editor 中运行以下SQL：
      ```sql
      -- 允许任何人插入数据
      CREATE POLICY "允许公开插入" ON survey_results
      FOR INSERT TO anon
      WITH CHECK (true);
      ```
- [ ] 5.2 点击 "Run" 执行
- [ ] 5.3 看到成功提示

**状态**: ⬜ 未完成 / ✅ 已完成

**可选权限**（如果需要在 admin.html 查看数据）:
```sql
-- 允许任何人读取数据
CREATE POLICY "允许公开读取" ON survey_results
FOR SELECT TO anon
USING (true);
```

## 🔍 第七步：故障排查

### 如果提交失败（控制台显示错误）

**错误 1**: "Supabase 未配置"
- [ ] 检查 `supabase-config.js` 中的 URL 和 Key 是否正确
- [ ] 确认 URL 不是 'YOUR_SUPABASE_URL'
- [ ] 刷新页面重试

**错误 2**: "new row violates row-level security policy"
- [ ] 确认已执行第五步的 RLS 策略 SQL
- [ ] 在 SQL Editor 中重新运行权限设置语句

**错误 3**: "relation 'survey_results' does not exist"
- [ ] 确认已执行 `setup-supabase.sql`
- [ ] 在 Table Editor 中检查表是否存在
- [ ] 重新执行 SQL 创建表

**错误 4**: 网络请求失败
- [ ] 检查网络连接
- [ ] 确认 Supabase 项目状态正常（未暂停）
- [ ] 清除浏览器缓存重试
