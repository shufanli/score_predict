# 复读适配性测试网站 - 启动说明

## 项目概述
这是一个复读适配性测试的纯静态网站，包含密码入口页、测试问卷页、以及结果页。当前版本不包含服务器端或数据库。

## 功能特点
- 📄 纯静态部署：可直接托管在任意静态空间（如 GitHub Pages、Vercel 静态、Netlify、Nginx 静态等）
- 🔒 密码保护：测试页面需要密码访问（前端校验）
- 📱 响应式设计：支持手机和电脑访问

## 启动与预览
- 本地直接用浏览器打开以下文件即可预览：
  - `index.html`（入口页，密码：7834520）
  - `test.html`（测试问卷页）
  - `result.html`（结果展示页）
- 建议使用本地静态服务器以避免跨文件引用限制（任选其一）：
  - Python 3: `python3 -m http.server 8080`
  - Node npx（无需项目依赖）: `npx serve .`
  - 或使用 VS Code Live Server 插件

## 部署
将 `Score_Predict` 目录内的静态文件上传到任意静态托管平台或放置到 Nginx 的静态目录下即可。

## 访问统计（可选）
本版本不再内置数据库与访问统计。如果需要统计，可选择接入第三方前端统计脚本，例如：
- Google Analytics / GA4
- Umami
- Plausible
- 百度统计（国内可选）

将相应平台提供的 `<script>` 代码片段加入 `index.html` 与 `test.html` 的 `<head>` 中即可完成集成。

## 目录说明（核心静态文件）
- `index.html` - 入口页（密码输入后跳转）
- `test.html` - 测试问卷页面
- `result.html` - 测试结果页面
