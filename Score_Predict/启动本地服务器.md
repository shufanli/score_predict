# 🚀 如何启动本地 HTTP 服务器

## ⚠️ 重要提示

如果你看到错误：`TypeError: Failed to fetch`

这是因为**直接用浏览器打开 HTML 文件**（`file://` 协议）无法使用 Supabase。

**必须通过 HTTP 服务器访问！**

---

## 🎯 解决方案（选择一个即可）

### 方法 1: 使用 Python（最简单，推荐）⭐

**适用于**: Mac / Linux / Windows（已安装 Python）

#### Python 3.x（推荐）

1. 打开终端/命令提示符
2. 进入项目目录：
   ```bash
   cd /Users/bzl/lishufan/代码文件/我的代码/score_predict/Score_Predict
   ```
3. 运行命令：
   ```bash
   python3 -m http.server 8000
   ```
4. 浏览器访问：http://localhost:8000/index.html

#### Python 2.x

```bash
python -m SimpleHTTPServer 8000
```

#### ✅ 成功标志

终端显示：
```
Serving HTTP on 0.0.0.0 port 8000 (http://0.0.0.0:8000/) ...
```

---

### 方法 2: 使用 Node.js / npm

**适用于**: 已安装 Node.js 的用户

#### 使用 http-server

1. 安装 http-server（只需一次）：
   ```bash
   npm install -g http-server
   ```

2. 进入项目目录：
   ```bash
   cd /Users/bzl/lishufan/代码文件/我的代码/score_predict/Score_Predict
   ```

3. 启动服务器：
   ```bash
   http-server -p 8000
   ```

4. 浏览器访问：http://localhost:8000/index.html

#### 使用 npx（无需安装）

```bash
npx http-server -p 8000
```

---

### 方法 3: 使用 PHP（如果已安装）

1. 进入项目目录
2. 运行：
   ```bash
   php -S localhost:8000
   ```
3. 访问：http://localhost:8000/index.html

---

### 方法 4: 使用 VS Code 扩展

**适用于**: 使用 VS Code 的用户

1. 安装扩展：**Live Server**
   - 打开 VS Code
   - 按 `Ctrl+Shift+X`（或 `Cmd+Shift+X`）
   - 搜索 "Live Server"
   - 点击安装

2. 使用方法：
   - 右键点击 `index.html`
   - 选择 "Open with Live Server"
   - 自动打开浏览器

#### ✅ 特点
- 自动刷新
- 无需命令行
- 支持热更新

---

### 方法 5: 使用在线部署（免费）

如果不想本地运行，可以部署到以下平台：

#### 5.1 GitHub Pages（推荐）

1. 将代码上传到 GitHub 仓库

3. 选择 main 分支
4. 保存并等待部署

2. 导入 GitHub 仓库或直接拖拽文件夹

4. 获得在线链接

#### 5.3 Netlify

1. 访问 https://netlify.com
2. 拖拽项目文件夹到页面
3. 自动部署
4. 获得在线链接

## 🔍 故障排查

### 问题 1: "Address already in use" / "端口被占用"

**原因**: 端口 8000 已被其他程序使用

**解决**: 使用其他端口
```bash
python3 -m http.server 8001
```
然后访问：http://localhost:8001/index.html

### 问题 2: "python3: command not found"

**原因**: 未安装 Python 或未添加到环境变量

**解决**:
- **Mac**: Python 3 已预装，尝试 `python3 --version`
- **Windows**: 从 https://python.org 下载安装
- 或使用其他方法（Node.js / VS Code）

### 问题 3: 服务器启动但无法访问

**检查**:
1. 确认终端显示 "Serving HTTP on..."
2. 浏览器访问 http://localhost:8000
3. 检查防火墙是否拦截
4. 尝试 http://127.0.0.1:8000

### 问题 4: 仍然显示 "Failed to fetch"

**可能原因**:
1. 仍然是 `file://` 协议（检查地址栏）
2. Supabase 项目未激活（访问控制台检查）
3. 网络连接问题
4. 权限策略未设置（执行 `set-permissions.sql`）
